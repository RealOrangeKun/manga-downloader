# Changelog

Written by the release workflow from the commit messages. Each version is a [GitHub Release](https://github.com/RealOrangeKun/nyanga/releases) with its installer.

## [1.2.0](https://github.com/RealOrangeKun/nyanga/releases/tag/v1.2.0) (2026-10-17)

### New
- search for a manga by name and pick it from the results
- settings: add an undo button and stay on settings until changes are saved or undone
- settings: saved defaults update the manga open on the download page
- split long file lists into pages
- one button to select all or none
- cat paw tick boxes instead of hearts
- settings: choose how many files each page lists
- sort the file list by tapping a column
- more ways to pick files: chapter range, shift-click, drag, quick picks and select page
- library: open a manga's folder from its card

### Fixes
- settings: let the settings page scroll so the window fits smaller screens
